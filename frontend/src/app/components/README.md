# Components

This directory contains the reusable components for the application.

## AddDishDialog

A dialog for adding a new dish.

## AddRestaurantDialog

A dialog for adding a new restaurant.

## DishCard

A card that displays information about a dish.

## FilterPanel

A panel that allows users to filter dishes and restaurants.

## ImageWithFallback

An image component that displays a fallback image if the original image fails to load.

## Navbar

The navigation bar for the application.

## RatingComponent

A component that allows users to rate dishes and restaurants.

## RestaurantCard

A card that displays information about a restaurant.
